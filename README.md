# EUROLYGOS MENEDŽERIS — 2026–2027

Privati 20 vadybininkų lyga, vizualiai pritaikyta pagal pateiktą pavyzdį.

## Kas jau įkelta
- 20 vadybininkų ir jų Eurolygos klubai;
- 1 turo poros;
- Pradžia, Lentelė, Tvarkaraštis, Rezultatai ir Komandos;
- W/L/B/+/-/PTS lentelės struktūra;
- playoff 1–6 ir play-in 7–10 zonos;
- mobilus dizainas;
- GitHub Actions automatinio atnaujinimo karkasas.

## Svarbu
Šiuo metu vadybininkų taškų automatinis nuskaitymas iš Krepsinis.net dar neprijungtas. Svetainė sąmoningai nerodo išgalvotų rezultatų.

Norint 100% automatikos, reikia patikimai nustatyti Krepsinis.net duomenų šaltinį, iš kurio teisėtai gaunami kiekvieno vadybininko turo žaidėjų taškai. Jei šaltiniui reikalingas prisijungimas, slaptažodžio į svetainės kodą nededame.

## Bonusas
bonusPoints reikšmė dabar yra 1 kaip laikina konfigūracija, kol bus patvirtintas tikslus tavo lygos bonuso dydis.
